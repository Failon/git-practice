# Симулятор роя
Распакуйте архив целиком. Откройте index.html в современном Edge или Chrome. Файлы JavaScript должны лежать рядом с HTML. Программа работает локально.

## Первый показ
Откройте «Пример», выберите пять дронов и нажмите «Старт». Светлый круг обозначает общий выход. Кнопка «Шаг» приостанавливает непрерывный прогон и выполняет один такт. «Сброс» восстанавливает стартовые позиции. Щелчок по свободной клетке переносит выход. Для индивидуального показа выберите одного дрона.

## Карты
Образец для загрузки находится в maps/passage.json. Поле rows содержит строки одинаковой длины, точка обозначает свободную клетку, решётка — стену. starts задаёт от одной до пяти пар [x,y], goal задаёт выход. Отсчёт начинается в левом верхнем углу с нуля. Генератор по числовому ключу создаёт воспроизводимую карту с достижимым финишем. Для загруженной карты приложение проверяет достижимость выхода от каждого выбранного старта.

## Алгоритм
core.js вычисляет поиском в ширину расстояния от выхода до всех доступных клеток. На каждом такте агенты в выбранном порядке приоритета выбирают соседнюю клетку с расстоянием на единицу меньше. Они пропускают клетки, занятые в начале такта или уже выбранные другим агентом. При равных вариантах проверяются направления вправо, вниз, влево, вверх. Если ход невозможен, агент ждёт. Агент на выходе завершает движение, выход снова доступен со следующего такта. Такой порядок исключает встречный обмен клетками, но может увеличивать ожидание. Модель ограничена одним общим выходом, статическими стенами и дискретным временем.

ui.js отвечает за интерфейс, паузу и анимацию. demo.js содержит встроенный пример. checks.js проверяет позиции после каждого такта. Для повтора автоматических проверок выполните node checks.js из папки проекта при установленном Node.js. Результаты сохраняются в results.csv. Для обычного запуска нужен только браузер.

## Очередность и повтор
Правило «Кто дольше ждёт» первым даёт ход дрону с наибольшим количеством последовательных пропусков. При равенстве первым ходит меньший номер. Кнопка «Сравнить правила» показывает для каждой очередности время финиша всей группы и сумму пропусков хода всеми дронами. Сравнение сохраняет текущую позицию просмотра.

Для показа выберите пять дронов, введите ключ 15, нажмите «Создать карту» и «Сравнить правила». По номеру получается 29 тактов и 14 пропусков, по длительности ожидания — 27 тактов и 9 пропусков.

Ползунок «История» останавливает движение и открывает записанный такт. Внизу показано, кто занял или выбрал спорную клетку. «С начала записи» возвращает на нулевой такт. «Шаг» или «Старт» воспроизводят историю и продолжают симуляцию за её концом. История хранится до сброса или смены сценария.

## Четыре показа и передача проекта
Из списка «Показ» выберите номер и нажмите «Открыть показ». Первый показывает данные, второй запускает одного участника перед стеной, третий — трёх, четвёртый — пять на карте с ключом 15. Кнопка «До первого ожидания» на четвёртом показе открывает такт 2. «Скачать карту» экспортирует текущие строки поля, все стартовые позиции и выход.

Модули проекта: demo.js — начальная карта; core.js — валидация, генерация, BFS, симуляция и история; ui.js — управление, рисование и показ результатов; index.html — точка входа. Вычисление расстояний на сетке выполняется за O(W×H), раз за сценарий. Четыре соседние клетки проверяются для каждого активного дрона на каждом шаге. История использует память пропорционально числу записанных тактов и агентов.

Проверки из папки Swarm: node checks.js и node check-ui.cjs. Первая команда создаёт results.csv. Вторая проверяет обработчики интерфейса с заменой DOM и Canvas тестовыми объектами. Для независимой проверки данных откройте maps/seed-15.json через «Открыть JSON».

Слайды для офлайн-защиты находятся в defense/slides.pdf, порядок демонстрации — в defense/SHOWS.md, задачи — в defense/tasks.csv.

```sh
git clone --single-branch --branch swarm-simulator https://github.com/Failon/git-practice.git swarm-simulator
```

В скачанном репозитории откройте index.html. При отправке изменений в эту ветку GitHub Actions запускает проверки алгоритма, обработчиков интерфейса и отдельную проверку в Edge на Windows.
